# Burning Hands Trap (CR 2)
Source: Core Rulebook, Environment, Traps, sample traps (Paizo). https://legacy.aonprd.com/coreRulebook/environment.html (verified 2026-09-25)

**Burning Hands Trap CR 2**
**XP** 600
**Type** magic; **Perception** DC 26; **Disable Device** DC 26

**EFFECTS**
**Trigger** proximity (alarm); **Reset** none
**Effect** spell effect (burning hands, 2d4 fire damage, DC 11 Reflex save for half damage); multiple targets

## Notes
- Area: burning hands is a 15-ft. cone, so the trap hits everyone in the cone (from the spell, not the trap entry).
- Magic traps can only be disabled by characters with trapfinding (or an equivalent ability; the bard archaeologist gets it only at 6th level); anyone can try to avoid or trigger them deliberately.
- Reskin used in sandpoint-delve: "starfire tiles" in the Listening Vigil (blue-white flash instead of flame; still fire damage). Trigger changed from proximity (alarm) to location (weight of 10 lb or more on the black tiles), which allows a safe trigger with a thrown weight; CR unchanged. Otherwise the mechanics are unchanged.
