# Settings
Campaign settings, one folder per setting: golarion/, or a homebrew or Claude-made setting. Settings are shared across campaigns and systems.
Everything here is DM knowledge. What the players know about a setting goes in each campaign's players/setting-primer.md.

Each setting folder has:
- overview.md: summary, tone, major powers, and the default era or timeline
- regions/, deities.md, factions.md and so on, added as they are needed
- source/: raw material the user provided (homebrew only)
- Anything Claude invented to fill a gap is marked [Claude invention]
