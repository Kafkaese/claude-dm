## Published-adventure spoilers
Apply `library/general/table-rules/published-content.md`. Signals checked 2026-09-25:

**PathfinderWiki**
- **Banner:** "This page contains spoilers for the following products: …" (the whole page), or "This section, and the rest of the article, contains spoilers for…" (from that section onward). Such pages are in **Category:Articles containing spoilers**. If the banner applies to the whole page, skip the page. If it's a section banner, use only the text above it.
- **Citations:** references render as `<Author>. "<Chapter>" in <Title>, NN. Paizo Inc., <Year>.` The title alone doesn't show that it's an AP. If a cited title's own page has an "Adventure Path issue" field, or is in an "… adventures" or "Pathfinder Modules" category, the fact comes from a published adventure.
- **NPCs:** there's no AP category for NPCs. Check the infobox's "Source" field against the rule above. An NPC whose only sources are adventures is adventure content.

**Archives of Nethys:** see `library/pf1e/sources.md`.
