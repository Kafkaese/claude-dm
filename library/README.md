# Library
Reference material that isn't tied to a campaign. Check here before searching online, and save useful lookups here with their source (book + page, or URL).

- general/: works with any system (random tables, safety tools, table rules)
- <system>/: system-specific rules and stat blocks, e.g. pf1e/. Never mix material from different systems.

A campaign uses general/ plus the folder named by the system field in its campaign.md.
